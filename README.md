# PDF Merger 

Just a simple app to merge PDFs. Drag, drop, merge, done.
Online PDF mergers are sketchy, slow, and often have file size limits. This is a simple, local solution.

## Usage

1.  Install dependencies: `pip install PyQt5 PyPDF2`
2.  Run: `python pdf_merger.py`
3.  Add PDFs, reorder them, and merge.
